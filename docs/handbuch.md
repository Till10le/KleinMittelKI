# Redaktionshandbuch – Überblick

Das vollständige Redaktionshandbuch (Ziel, Zielgruppe, Rubriken, Stil, CI, Grafiken, Newsletter, Verbreitung,
Fahrplan) ist auf die Skills in `.claude/skills/` verteilt, damit Agenten nur laden, was sie brauchen:

| Thema | Skill |
|---|---|
| Ton, Wendungen, Verbote | `kmk-schreibstil` |
| Rubriken, Kategorien, fünf Beitragsformate | `kmk-formate` |
| Themenauswahl, Quellen, Dubletten | `kmk-themen` |
| Farben, Schriften, Logo, Grafik-Baukasten, Vorschaubild | `kmk-ci-grafik` |
| Ghost, Entwürfe, Freigabe-Sperre | `kmk-ghost` |
| Newsletter | `kmk-newsletter` |
| LinkedIn, Instagram, WhatsApp | `kmk-social` |

Die menschenlesbare Fassung pflegt Till als Claude Doc „Redaktionshandbuch KLEIN. MITTEL. KI.“ im Projekt „Blog“.
Ändert sich dort etwas Grundsätzliches, wird es hier im Repo nachgezogen (über eine Pull Request).

## Ziele und Fahrplan (Stand 18.10.2026)

- Langfristig: Till als Experte für KI im Mittelstand sichtbar; Grundlage für spätere Beratung.
- Nächste Monate: jeden Dienstag ein Hauptbeitrag und ein Newsletter, ohne Ausfälle. Verlässlichkeit vor Reichweite.
- Testlauf seit Go-live am 28.09.2026 (vier Wochen), danach Namensentscheidung.
- Nach 6–8 Newsletter-Ausgaben: Öffnungsraten und Antworten auswerten.
